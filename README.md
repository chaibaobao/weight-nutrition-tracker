# 体重与营养记录

一个面向手机浏览器、简体中文、无账号的个人体重与饮食记录工具。V1 的个人资料、体重、饮食、自定义食品、收藏和历史快照全部保存在当前浏览器的 IndexedDB 中。

## 功能

- kg / 斤输入与显示，内部统一使用 kg
- 最近 15 个自然日的有效体重平均（缺失日期不补 0）
- 按实际脂肪摄入自动切换低脂 / 高脂方案
- BMR 参考、营养目标、今日剩余与历史快照
- 约 100 种中国大陆常见食品、自定义食品、kJ 换算、每份录入
- 收藏、最近使用、饮食快照与再次添加
- 体重 / 营养趋势，以及 7 / 30 / 90 天 / 全部范围
- JSON 完整备份、校验恢复、含 BOM 的 CSV 导出
- 基础 PWA Manifest，可添加到主屏幕

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址。

## 检查与构建

```bash
npm run typecheck
npm test
npm run build
```

构建结果位于 `dist/`。Vite 使用相对资源路径，适配 GitHub Pages 仓库子路径。

## 数据、隐私与迁移

个人记录数据默认只保存在当前浏览器，不会上传服务器，也不会自动云同步。GitHub 仓库只保存程序代码，不包含个人记录。

首次在线打开并完成加载后，应用外壳会保存到当前浏览器；之后即使断网，也可以重新打开应用并继续记录。离线期间新增或修改的数据仍写入 IndexedDB，恢复网络后不会上传。发现新版本时，应用会先提示，由你选择何时更新。

换手机或更换浏览器前：

1. 在“我的 → 数据管理”导出 JSON 备份；
2. 将备份文件安全传到新设备；
3. 在新设备打开 App，进入“我的 → 导入备份”；
4. 确认校验结果后导入。

CSV 用于查看或分析，不用于完整恢复；完整恢复请使用 JSON。

## GitHub Pages

`.github/workflows/deploy.yml` 会在 `main` 分支更新后自动执行依赖安装、TypeScript 检查、测试、构建并部署 Pages。仓库 Settings → Pages 的 Source 需设为 **GitHub Actions**。

## 算法版本

历史快照的 `algorithmVersion` 为 `v1`。未来算法升级不会静默重写已有历史快照。
